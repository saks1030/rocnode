# Aternos Clone

This is a clone of the Aternos website, built with the MERN stack (MongoDB, Express, React, Node.js).

## How to Run

### Prerequisites

- Node.js and npm
- MongoDB

### Backend

1. Navigate to the `backend` directory.
2. Run `npm install` to install the dependencies.
3. Run `npm start` to start the backend server.

### Frontend

1. Navigate to the `aternos-clone` directory.
2. Run `npm install` to install the dependencies.
3. Run `npm start` to start the frontend development server.
